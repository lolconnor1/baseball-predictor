How it works

Baseball Oracle predicts the winner of every MLB game. Each morning a scheduled GitHub Actions job pulls the latest results from the MLB Stats API, rebuilds the model's features for every game using only information available before first pitch, retrains a random forest, and publishes the predictions on this site. No server, no manual steps.

The pipeline

  1. 1
    Collect

    Every regular-season game since 2021 from the MLB Stats API: results, probable starters, plate umpires, box scores, and per-game logs for every starter and team. Game-day weather from Open-Meteo.

  2. 2
    Build features, as of the day before

    53 features per game: starter quality and recent form, lineup strength against the starter's handedness, bullpen quality and workload, team form, rest and travel, park, weather and umpire. Each stat is rebuilt from game logs using only games played before that date, and shrunk toward last season's numbers early in the year.

  3. 3
    Validate walk-forward

    Each season is predicted by a model trained only on earlier seasons. Random forest and XGBoost are both tried; the one with the lower out-of-sample log loss wins.

  4. 4
    Calibrate

    Platt scaling, fit on those out-of-sample predictions, turns raw forest scores into probabilities that mean what they say.

  5. 5
    Predict and publish

    The model is retrained on everything, today's games are scored, and predictions are locked in before first pitch. The site is static: just HTML and JSON files rebuilt by the pipeline.

The data leak I found

An earlier version of this model scored 60.5% on its test season. That would beat the betting market, which is a red flag rather than a result. The cause: pitcher, bullpen and batting-split stats were season totals, so a game in April already "knew" how a pitcher would finish in September.

Rebuilding every stat as of the day before each game dropped accuracy to 55.3%, in line with what the old model had actually done on live games. The lower number is the honest one, and it's the one everything on this site reports.
